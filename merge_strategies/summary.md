## merge commit 
When we do merge commit two branches are merge together all the commits of the second branch are commit with creating a new commit. 
## squash and merge 
We can also merge two branches with squash.
The difference in normal and squash merge is that
Normal -> it added all the commits one by one to merge branch
squash -> It makes all the other branch commits as one commit and added it to the branch.
## rebase and merge 
Take my commits and replay them on top of another branch.

Instead of merging two branches together, Git moves your commits so they look as if they were created from the latest version of another branch.
It make the commit graph in a linear way.
